# MATPredict: prediction of MAT loci in fungi

Framework:
Develop curated set of model MAT locus representation for differnet taxonomic groups.

Use translated searches to identify key loci and flanking genes. Classify MAT type by typical naming scheme for the group.

Extract the locus region, genes, and provide these as a standardized report along with figures and tables.

Visualize synteny of the genome regions across sets of species.
