## The three things most likely to bite a fresh session

* **`/scratch` is NODE-LOCAL.** A worktree, work directory or any path a
  SLURM job must see belongs on `/bigdata`. A bad `$PYTHONPATH` does NOT
  raise -- python falls back to the INSTALLED MATPredict and the job runs to
  completion against the wrong code, producing normal-looking reports. Five
  panels did exactly that. `run_clade_panel.slurm` now refuses to start when
  `$SRC/MATPredict/__init__.py` is absent; keep that guard in any new runner,
  and verify a change actually ran by grepping a finished report for a field
  only the new code writes.
* **Never edit the working tree while a run is in flight.** It cost 277 of
  2,283 genomes once. Use a worktree.
* **`--taxid` is not optional in a benchmark run.** Without it routing falls
  back to `exhaustive`: 27 min/genome instead of ~2, and the wrong experiment,
  since exhaustive is not the configuration anyone runs.

## How to read a recall number here

Per radius, never pooled, and always with `no_reference` separated from a
genuine miss -- both the family kind (no record of the family survived the
holdout) and the idiomorph kind (records survived but none for the idiomorph
sought; idiomorphs are non-homologous by definition, so that target is
structurally unfindable). Conflating them understated recall by 12 points on
the first pass of this very analysis.
