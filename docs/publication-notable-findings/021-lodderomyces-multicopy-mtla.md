# 021. Lodderomyces beijingensis: MTLa-like blocks on seven chromosomes

- **Category:** assembly-or-annotation artefact (unresolved)
- **Status:** candidate
- **Lineage:** Ascomycota, Serinales

## Summary
One Lodderomyces beijingensis assembly carries MTLa1+MTLa2-like blocks at near
identical identity on seven chromosomes, four starting at the same coordinate.
It gives eight high-confidence A calls in one genome.
