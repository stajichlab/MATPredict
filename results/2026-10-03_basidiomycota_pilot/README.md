# Basidiomycota pilot on v0.6.0 (2026-10-03)

163 BFD Basidiomycota genomes, stratified by ORDER (57 orders; about 100 x order share,
at least 2 per order; random.seed 20261003). Lists: pilot_list.tsv, pilot_meta.tsv.
Code: frozen worktree run-7c7ed99 (= v0.6.0). Partition exfab, 32-way, GENOME_TIMEOUT 14400.
Purpose: per-genome runtime and call rate per order on current code, and a call-by-call
comparison with the 2026-09-26 full run (run-ad1f865) on the same genomes.
