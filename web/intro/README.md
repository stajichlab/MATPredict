# Project intro pages

The public landing page (`landing.html`, published as the site root) and the results explorer (`results.html`).
Static HTML and JavaScript with no dependencies; the browser tool itself lives in `../spike/`.

- `data/summary.json`, `data/taxa.json`: generated by `python3 scripts/build_site_data.py` from the committed
  campaign tables under `results/` (BFD Ascomycota, Basidiomycota, Mucoromycotina; ZyGoLife LCG and Jena).
  `web/spike/page/build-site.sh` regenerates them on every Pages build; rerun by hand after new campaign results. Which `results/` folders are read is set once, in `RELEASES` in that script (`v060`, the live site, stays the default until the results PR switches it to `cleanrun`; each dataset is labelled with its own folder's code and mixed generations are refused); the clean-run tables come from `scripts/build_cleanrun_tables.py` and add the reporting columns (`baseline_confidence`, `tier_note`, `label_unsupported`, `high_basis`). The held-out ZyGoLife sets are a separate category, outside the BFD headline cards and off by default in the explorer. The release step is in `docs/notes/2026-10-24_site-data-step.md`.
- `data/genomes_<dataset>.tsv`: per-genome tables (one row per genome, loci listed). Git-ignored; written by the same script and linked from the explorer, which can also export just the genomes in its current view.
- `data/cocci_reads.json`, `data/cocci_reads.tsv`: Coccidioides read-typing summary and compact per-strain table, written by the same script from `datasets/reads/coccidioides/results/cocci2_reads_vs_detect.tsv` and shown in the landing page's raw-reads section. Committed.
- Preview: `python3 -m http.server --directory web/intro` and open `landing.html` (the landing page links to the
  tool at `page/index.html`, which exists only in the assembled site).
- Numbers in the benchmark and raw-reads tables of `landing.html` are written by hand from `analysis/` notes; update them with the notes. Every hand-written number and where it comes from is listed in `docs/notes/2026-10-24_site-data-step.md`. The code label in the notice is filled from `summary.json` (`release.code`).

- Themes: `theme.js` (loaded in `<head>`) applies the saved choice (`localStorage`, key `matpredict-theme`) before first paint; Auto follows the system. Colours are tokens in `site.css` (light, dark, paper, neuromancer). Chart colours c1-c6 plus semantic `undet`, `two`, `other`, `uncalled`; `charts.js` only references the tokens. The tool page (`web/spike/page/index.html`) has its own styling and does not use these themes yet.
- Locus maps: `data/loci_<dataset>.json.gz` (committed, about 1.6 MB for all 27.8k loci) hold each detected locus with its gene models, extracted from the campaigns' `reports_all.tar.zst` by `scripts/build_locus_shards.py` (needs PyYAML and `zstd`; rerun when a campaign changes). `locus-view.js` draws them in the explorer and links contig accessions to NCBI nuccore.
- About page: `about.html` renders `about.md` in the browser with `md.js` (a small Markdown subset; HTML in the file is escaped, and `<!-- -->` comments, used for [UPDATE] notes, are dropped). Edit `about.md` to change the citation, data sources, funding or acknowledgements; no HTML needed.
- Explorer navigation: the view (rank and the taxa clicked into) is kept in the URL hash, e.g. `results.html#rank=species&phylum=Ascomycota&genus=Xylaria`, so Back and copied links work. The "Within:" trail, "Up one level" and Reset move between levels.

- `reads/` (overview and per-species report) read `data/reads/*.json`, written by `scripts/build_reads_site.py` at site build time (git-ignored). `data/cocci_reads.*` are still written by `build_site_data.py` but the landing page no longer uses them.
