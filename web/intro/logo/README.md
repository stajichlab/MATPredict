# MATPredict logo

A lens finding the mating-type locus: the locus drawn in the explorer's own gene-map colours (green flank genes, blue core MAT gene, pale-yellow called span). Made 2026-10-26.

| File | Use |
|---|---|
| `horizontal.svg`, `horizontal-dark.svg` | Site header; the dark file is for dark backgrounds (light wordmark, dark-theme colours) |
| `stacked.svg`, `stacked-dark.svg`, `stacked-mono.svg` | Square lockup, lens above the name (README, posters, social cards); the mono file is one colour (`color` sets it) |
| `favicon.svg` | Browser tab icon (the lens alone); `lens-dark.svg` is its dark-theme version, `lens-mono.svg` one colour |

Wordmark: the letters are outlines traced from Nunito (ExtraBold for "MAT", Medium for "Predict"), which is licensed under the SIL Open Font License 1.1 (`OFL-Nunito.txt`); no font is needed to display it. The text fill follows the CSS `color` of an inline SVG; in an `<img>` it is fixed (#1d1d1f, or #f2f2f4 in the `-dark` files).
The mark reads down to about 32 px; below that it is a ring with a yellow and blue centre.
