MATPredict in the browser

Upload a fungal genome (FASTA or GenBank). The detection pipeline runs in this page: Python in Pyodide, the search tools as WebAssembly. Nothing is uploaded to a server.

This page must be served over HTTP. Opened from a file, the browser blocks the modules and data it loads, so the upload stays disabled. From web/spike run python3 -m http.server 8000, then open http://localhost:8000/page/index.html.
