MATPredict

Find the mating-type (MAT) locus in a fungal genome, with the genes that flank it.

Open the browser tool Source on GitHub

Experimental. The browser tool is a spike. It runs the same detection logic as the command-line MATPredict, but the browser version has not yet been checked on every platform or against the full benchmark. For published results, use the command-line tool.

What it does

  • Takes a genome assembly in FASTA format (.fa, .fasta, .fna), plain or gzipped.
  • Finds the MAT locus, the idiomorph (for example MAT1-1 or MAT1-2, or Plus and Minus in Mucoromycota), and the flanking genes.
  • Shows a results table, a figure of the locus with its flanks, the sequence with the locus highlighted, and the full report to download.

Your genome stays on your computer

The analysis runs in your browser. The genome is not uploaded to any server. The first visit downloads about 35 MB of tools and reference data, which the browser then caches. Results are only as good as the assembly you provide.

Requirements

  • A recent desktop browser: Chrome, Edge, Firefox, or Safari. Large genomes need several gigabytes of free memory.
  • JavaScript enabled. The tool does not work from a file opened on disk; use this website.

Command line and other tools

MATPredict is also a Python package with a command-line interface, for batch runs and reproducible analyses. See the repository for installation and documentation.

The browser tool uses third-party software under their own licences, including MMseqs2 and exonerate (GPL), miniprot, LOSAT, HMMER and pyhmmer. Source for each pinned version is in the repository. Python runs with Pyodide.
